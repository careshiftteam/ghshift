# GHShift

---

## 1. GHShiftは何をしてくれるの?

介護施設のシフト作成は、毎月とても時間がかかる作業です。GHShiftは、

- 必要な人員配置基準を満たす**最小人数の組み合わせ**を自動で計算し
- 急な欠勤が出たときも、影響を最小限にしてシフトを組み直し
- スタッフ自身がスマホやパソコンから、自分のシフトを確認できる

ようにするためのツールです。今はまだ「ドラフト版」なので、不具合や使いにくい部分もあると思いますが、少しずつ改善していく予定です。

---

## 2. 始める前に知っておいてほしいこと

- GHShiftは**ダウンロードして、自分の施設のパソコン(サーバー)にインストールして使う**タイプのアプリです。GHShift側がスタッフのデータを預かることはありません。
- 生成されたシフトは「たたき台」です。法令(労働基準法など)や就業規則に合っているか、最終的には必ず人の目で確認してください。
- 無保証でのご提供です。動かなかった場合の責任は負いかねますが、掲示板で報告いただければできる範囲で対応します。

## 3. 準備するもの(動作環境)

パソコンの知識がなくても大丈夫です。以下の2つだけ、順番に用意すればOKです。

| 必要なもの | かんたんに言うと | 入手先 |
|---|---|---|
| Python(パイソン) | このアプリを動かすための土台となるソフト | [python.org](https://www.python.org/downloads/) から無料でダウンロード |
| GHShiftのファイル一式 | このアプリ本体 | このGitHubページの「Code」ボタン →「Download ZIP」 |

対応OS:Windows / Mac どちらでも動作します。

## 4. セットアップ手順

### ステップ1:GHShiftをダウンロードする

1. このページ上部にある緑色の「Code」ボタンをクリック
2. 「Download ZIP」をクリック
3. ダウンロードされたZIPファイルを、わかりやすい場所(例:デスクトップ)に展開(解凍)する

### ステップ2:Pythonをインストールする

すでにパソコンにPythonが入っている場合は、この手順は飛ばしてください。

1. [python.org](https://www.python.org/downloads/) を開き、「Download Python」ボタンからインストーラーをダウンロード
2. インストーラーを実行する際、**「Add Python to PATH」というチェックボックスに必ずチェックを入れてから**「Install Now」を押してください(これを忘れるとうまく動きません)

### ステップ3:必要な部品(ライブラリ)をインストールする

1. 展開したGHShiftのフォルダを開き、フォルダの中の何もない場所で右クリックします
   - Windowsの方:「ターミナルで開く」または「コマンドプロンプトをここで開く」を選んでください
   - Macの方:フォルダを右クリック(または2本指クリック)し、「サービス」→「フォルダに新規ターミナル」を選んでください。表示されない場合は、「ターミナル」アプリを開き、`cd ` と入力した後にGHShiftフォルダをターミナルの画面にドラッグ&ドロップし、Enterキーを押してください
2. 開いた黒い画面(コマンド画面)に、以下をそのまま入力してEnterキーを押します

   ```
   pip install -r requirements.txt
   ```

   これで、GHShiftを動かすために必要な部品が自動でインストールされます。少し時間がかかります。

### ステップ4:GHShiftを起動する

同じ黒い画面で、以下を入力してEnterキーを押します。

- Windowsの方
  ```
  start.bat
  ```
- Macの方
  ```
  bash start.sh
  ```

「Running on http://127.0.0.1:5000」のような表示が出れば起動成功です。この画面は閉じずに、そのまま開いたままにしておいてください(閉じるとGHShiftも止まります)。

はじめて起動したときに、データを保存するためのファイル(データベース)が自動で作られます。特別な準備は必要ありません。

### ステップ5:ブラウザで開く

1. Chrome や Edge などのブラウザを開く
2. アドレスバーに以下を入力してEnterキーを押す

   ```
   http://127.0.0.1:5000
   ```

3. GHShiftの画面が表示されれば完了です

> ⚠️ **重要:初期パスワードは必ず変更してください**
> GHShiftの初期管理者パスワードは `admin1234` です。このパスワードはソースコード上に公開されているため、**変更せずに使い続けると、外部の人でもログインできてしまう危険があります**。ログインできたら、真っ先にパスワードを変更してください。特に、スタッフが外出先からもアクセスできるように設定している施設では、必ず対応してください。
